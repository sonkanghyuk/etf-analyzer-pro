# 존버나드 쇼츠 스튜디오 구현 계획

## 조사 결과 (2026-10-16)
- `/workspace`에는 `etf-analyzer-pro`만 존재. Johnber 코드와 AGENTS.md는 없음. 기존 앱과 파일을 보존하고 별도 `johnber-shorts-studio` 폴더에 구현한다.
- 첨부 TXT에 상세 개발 명세와 A01–A17 검수 기준이 통합되어 있음. 별도 01/02/03/04 문서, 참고 스크린샷은 제공되지 않음. 앞선 UI 녹화는 전송 제한으로 접근할 수 없음. 따라서 화면 관찰을 했다고 주장하지 않고 명시된 3패널 구조를 독립 디자인으로 구현한다.
- Python 3.12, FFmpeg/ffprobe 7.1, Noto CJK 글꼴이 있음. Windows에서는 Python 3.12+, FFmpeg, 맑은 고딕을 사용한다.

## 구조 결정
- FastAPI + 정적 HTML/CSS/JavaScript: Node 빌드 없이 Windows 로컬 실행.
- 버전 있는 JSON 문서와 원자적 저장, 한 번에 하나의 영속 작업 큐. localhost 기본, 원본은 해시 기반 별도 보존.
- 모든 시간은 원본 기준 초(double). 공통 EDL에서 삭제/배속/자막 시간을 변환한다. FFmpeg 출력 프레임은 30fps로 양자화한다.
- Pillow로 1080×1920 자막/제목 레이어를 그려 미리보기와 최종 MP4에 공유한다. UI 드래그는 좌표 편집, 확정 PNG/프리뷰 MP4는 공통 렌더러의 결과다.
- AI는 선택 기능. 원격 호출과 모델 다운로드에 명시적 동의 필요. 키·모델 미연결 상태와 규칙 기반 후보를 구분한다.

## 단계별 검수
1. M1: 자체 제작 모서리/시간/음향 표식 영상 + 한국어 SRT → 저장 프로젝트 → 제목/자막 포함 실제 H264/AAC MP4. ffprobe, 디코드 프레임 확인.
2. M2: 실제 제공자 인터페이스/검증/캐시, 선택적 로컬 ASR. 인증·한국어 실제 음성 자료 없이는 A03/A04 전체 PASS 금지.
3. M3: 비파괴 cuts/배속/무음 제안, 템플릿 버전, 3클립/ZIP, 진행/취소/재시도/재시작 복구, 브라우저 검증.
4. README/Windows 실행 도구/.env.example, 검수 보고서와 PROGRESS.md 기록.

## 자산과 안전
참고 영상은 UI 참고일 뿐 입력·배경으로 사용하지 않는다. ENLIT 로고/폰트/이미지 복제 없음. 실제 키 저장/출력 금지. 결제·외부 게시·공개 배포·관리자 권한 변경 없음.
