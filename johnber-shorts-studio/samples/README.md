# 자체 제작 검수 샘플

모든 파일은 이 앱의 테스트가 직접 만든 자료입니다. 참고 UI 녹화·실제 강의·참고 서비스의 이미지/로고를 사용하지 않았습니다. 소리도 한국어 발화가 아닌 880Hz 동기화 신호입니다. 숫자·티커는 글꼴과 기호 검수용 문자열이며 투자 주장으로 쓰지 않습니다.

1. `demo-source.mp4`를 새 프로젝트로 업로드합니다.
2. `demo-subtitles.srt`를 불러와 수동 구간/제목을 편집하고 내보냅니다.
3. 검증된 편집을 재현하려면 **같은 원본 업로드 후**, 프로젝트 목록의 ‘프로젝트 열기’에서 `demo-project.json`을 가져옵니다. 원본 해시가 일치해야 합니다.
4. `demo-export.mp4`는 4~6초 삭제 + 1.25배속을 적용한 실제 6.4초 결과입니다.

원본 모서리 4색 표식, 시간 표시, 플래시와 음향 신호를 사용해 원본 보존·동기화를 검사했습니다. 이 자료만으로 한국어 ASR 정확도를 검증했다고 주장하지 않습니다.
