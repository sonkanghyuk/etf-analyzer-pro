외부 캡처 화면(S&P500 히트맵, 트레이딩 차트, 외신 차트)은 원 서비스의 색을 그대로 쓴다. 히트맵 녹색 `#40A054`/`#5ED173`, 적색 `#D42A3C`.

### 3-2. 색 = 의미 규칙
1. **네이비가 기본값.** 의미를 부여하지 않은 데이터는 전부 네이비.
2. **레드는 '여기를 보라'.** 하락 수치뿐 아니라 상승이라도 화자가 강조하는 숫자("40% 이상", "$317억 감소")와 비교의 주인공 막대에 레드를 쓴다. 한 화면에 레드 요소는 **1~2개**까지.
3. **초록은 상승·매수에만.** 강조용으로는 쓰지 않는다.
4. **회색은 과거·비교 대상·보조 라벨.**
5. 상승/하락은 **미국식**(상승 초록 · 하락 빨강). 4대 지수 링, 주가&환율 링, BUY/SELL, 상승/하락 종목 분할 화면 모두 이 규칙을 따른다.

> ⚠️ 존버나드TV 기존 쇼츠 카드(`shorts_card.py`)는 **한국식(상승 빨강·하락 파랑)**이다. 롱폼에서 레퍼런스 규칙을 그대로 따를지, 채널 전체를 한국식으로 통일할지는 결정이 필요하다. 파이프라인은 `color_convention: us | kr` 설정 하나로 바꿀 수 있게 설계했다(파이프라인 문서 §5). **[권장] 롱폼은 미국식** — 다루는 자산이 미국 주식이고, 레드를 '강조'로 겸용하는 이 스타일의 문법이 한국식에서는 충돌한다(상승 강조와 하락이 같은 색이 됨).

## 6. 자막 규격

### 6-1. 모양
- 위치·크기: §2 표 그대로. 바는 **텍스트 길이와 무관하게 고정 폭** 1358px. "감사합니다" 다섯 글자일 때도 같은 폭이다. [실측]
- 바: `#000000`, 불투명도 71%, 모서리 반경 10px, 테두리·그림자 없음. [실측]
- 글자: 흰색, 테두리(stroke) 없음, 그림자 없음, 가운데 정렬, 바 높이의 세로 중앙(글자 띠 y 966~1017). [실측]
- **한 줄만** 쓴다. 두 줄 자막은 관측되지 않았다.
- 실사·차트·종이 배경 구분 없이 **모든 화면에 같은 규격**으로 깐다(로고 스팅 화면 제외).

### 6-2. 글자 수와 끊는 법
- 공백 포함 **최대 24자**. 12개 실측 샘플: 5·9·13·13·16·19·20·20·22·23·24자.
- 한 문장(중앙값 26음절)을 대개 **2개 청크**로 나눈다. 대본 전체를 24자 규칙으로 잘라 보면 청크 평균 17.3자(중앙값 20자), 영상당 361~565개.
- 끊는 위치 우선순위:
  1. 쉼표·연결어미 뒤: `~는데` `~하고` `~하면서` `~지만` `~면` `~니까`
  2. 주어·목적어 덩어리 뒤: `[젠슨 황이 엔비디아로 복귀하고] / [증시는 핫했죠]`
  3. 부사어 뒤: `[다행히 오늘 새벽,] / [젠슨 황이 복귀했습니다]`
- 끊으면 안 되는 곳: 숫자+단위(`12.8%`, `4,281억 원`), 고유명사(`S&P 500`, `나스닥 100`), 관형어+명사(`~하는 / 것`), 보조용언(`~해야 / 합니다`).
- 문장 끝 마침표는 **지운다**. 쉼표, 물음표, %, 따옴표는 남긴다. 예: `어떤 투자가 나와 결이 맞다고 생각하시나요?` [실측]
- 숫자는 아라비아 숫자, 천 단위 쉼표, 단위 한글(`3조 4천억 달러`, `1,330원대`). 티커는 대문자(`SOXL`, `QQQ`).

### 6-3. 타이밍
- 청크는 해당 첫 단어 발화와 동시에 켜고, **다음 청크 시작 순간까지** 유지한다(공백 없음). 문장 사이 쉼이 0.6초보다 길면 0.3초 뒤에 끈다. [권장]
- 평균 표시 시간 **2.2~2.3초**, 최소 0.8초 [실측 평균 / 권장 최소].
- 자막 텍스트는 대본 원문을 쓰되 군말("어", "음")·말실수는 지운다. 수치는 화면 슬라이드와 **같은 표기**로 맞춘다.

### 8-3. 강조가 나오는 타이밍
- 강조 오버레이(빨간 원, 검정 테두리 사각, 초록 체크, 날짜 태그, 헤드라인 박스)는 **내레이션이 그 대상을 말하는 순간 0~2초 안에** 뜬다.

### 9-6. 말투 통계 [실측: 4편 918문장]

| 지표 | 값 |
|---|---|
| 말 속도 | 371~380음절/분 (6.2음절/초) |
| 문장 길이 | 중앙값 24~26음절(공백 제외), 평균 26~29, 상위 10% 38~44 |
| 어절 수 | 중앙값 7~9, 평균 7.9~9.2 |
| 문장당 시간 | 4.1~4.75초 |
| 어미 분포 | `~습니다/~ㅂ니다` 56~59% · `~죠(?)` 18~23% · `~는데요` 15~20% · `~고요` 1~4% · 기타 `~요` 1~3% |
| 물음표 문장 | 2~4% (대부분 묻고 바로 답하는 수사 의문문) |

**문장 규칙 [권장]**
1. 한 문장에 정보 하나. 26음절 안팎, 40음절을 넘으면 둘로 나눈다.
2. 리듬: `~습니다`(사실 전달) 2~3문장 → `~죠`(공감·확인) 1문장 → `~는데요`(다음 정보로 연결) 1문장을 돌려 쓴다.
3. 숫자는 한 문장에 **최대 2개**. 세 번째 숫자는 다음 문장으로.
4. 주어는 '우리'(우리 주식 계좌, 우리 구독자분들), 판단은 '저'(저는 ~ 판단합니다). 단정 대신 "~볼 수 있겠습니다", "~가능성이 높은 상황입니다".
5. 공포를 부추기지 않는다. 하락장 멘트는 "버텨야 합니다 / 이 또한 지나가리라" 같은 정서적 지지로 닫는다.

### 9-7. 존버나드TV로 옮길 때
- 구조·호흡·화면 문법은 그대로 쓰되, **채널 고유 요소는 반드시 바꾼다.**
  - 로고: 존버나드TV 로고 PNG(투명 배경)를 §2 로고 박스(252×120)에 맞춘다. SUPETV의 3D 로고 모양을 흉내 내지 않는다.
  - 인사·슬로건: "돈을 공부하는 남자", "여러분의 관심이 저를 행복하게 합니다", "오늘도 성공" 같은 레퍼런스 고유 문구는 쓰지 않는다. 예시 대체안: `안녕하세요, 끝까지 버티는 투자자 존버나드입니다.` / 클로징 `오늘도 존버 성공하세요.`
  - 진행자 캐리커처·인물 일러스트는 직접 제작하거나 라이선스 있는 소스를 쓴다.
- 히트맵·차트·기사 캡처는 출처를 반드시 우하단에 표기한다. 가능하면 파이프라인이 원 데이터로 **직접 그린 차트**를 쓴다(파이프라인 문서 §6).
