# 존버나드 쇼츠 스튜디오 (Johnber Shorts Studio)

긴 강의·주식·ETF·경제 해설 영상을 등록하고, 자막(SRT/VTT·수동 입력·로컬 자동 전사)과 구간(수동 또는 AI 추천)을 골라
**제목·자막이 들어간 세로 1080×1920 MP4**를 여러 개 만드는 개인용 로컬 웹앱입니다.

- 원본 가로 영상은 기본적으로 **잘리지 않게 전체 보존(contain)** 해서 세로 화면 가운데에 넣고, 위에 제목·아래에 자막을 배치합니다. 얼굴 자동 크롭은 쓰지 않습니다.
- 미리보기와 최종 MP4는 **같은 렌더러가 만든 같은 PNG**(제목·자막·강조)와 **같은 시간 매핑(EDL)** 을 씁니다.
- AI 키가 없어도 SRT/수동 자막 + 수동 구간 → MP4 출력은 모두 동작합니다. 가짜 AI 결과는 만들지 않습니다.
- 참고 서비스(ENLIT)의 로고·템플릿 이미지·글꼴은 포함하지 않았습니다. 동봉 글꼴은 SIL OFL 1.1 나눔 글꼴(`fonts/OFL-NANUM.txt`)뿐입니다.

> 이 폴더는 같은 저장소의 ETF Analyzer(Streamlit, 상위 폴더)와 독립된 프로그램입니다. 기존 파일은 수정하지 않았습니다.

## 1. 설치 (Windows)

1. **Python 3.10 이상** 설치: <https://www.python.org/downloads/windows/> — 설치 화면에서 *Add python.exe to PATH* 체크.
2. **FFmpeg** 설치(택1)
   - 명령 프롬프트/PowerShell: `winget install --id Gyan.FFmpeg`
   - 또는 <https://www.gyan.dev/ffmpeg/builds/> 에서 받아 압축을 풀고 `.env`의 `JSS_FFMPEG`, `JSS_FFPROBE`에 `ffmpeg.exe`, `ffprobe.exe` 경로 지정
3. 이 폴더의 **`설치.cmd`** 더블클릭 → 가상환경(`.venv`)과 패키지 설치, `.env` 생성, FFmpeg 확인.

관리자 권한은 필요 없습니다. 설치 도구는 결제·계정·시스템 설정을 바꾸지 않습니다.

## 2. 실행·종료

- 실행: **`실행.cmd`** 더블클릭 → 브라우저가 `http://127.0.0.1:8765/` 로 열립니다(포트가 사용 중이면 다음 번호를 자동 선택).
- 종료: 실행 창에서 `Ctrl+C` 후 창 닫기. 렌더링 중에 종료하면 다음 실행 때 그 작업은 **중단됨(재시도 가능)** 으로 정리되고, 이전 완성본은 보존됩니다.
- 다른 OS/개발용: `pip install -r requirements.txt` 후 `python run.py`

브라우저는 Chrome 또는 Edge를 권장합니다. 원본 코덱(HEVC 등)을 브라우저가 재생하지 못하면 미리보기 화면의 **‘재생용 프록시 만들기’**(로컬 WebM 생성)를 누르세요. 출력에는 영향을 주지 않습니다.

## 3. 사용 흐름

1. **프로젝트** → 영상 파일 끌어오기(앱 데이터 폴더에 사본 보관) 또는 **PC 경로로 등록**(복사 없이 원위치에서 읽기, 큰 강의 파일에 권장). 길이·해상도·fps·음성 유무·SHA-256을 실제 파일에서 검사합니다.
2. 편집 화면 가운데 **‘전사문·구간 선택’** 탭: SRT/VTT 불러오기 · 수동 자막 입력 · 자동 전사(로컬) 중 선택. 형식 오류·겹침·빈 문장·인코딩을 검사해 보여줍니다. 원문 보존본과 교정본(버전)이 따로 저장됩니다.
3. 구간 고르기: 문장의 ‘시작/끝’ 버튼 또는 시각 입력으로 **수동 클립**, 또는 오른쪽 **AI 추천**(키 필요) / **규칙 기반 후보**(AI 아님, 무료).
4. **클립 자막** 탭에서 문장 교정·강조·줄바꿈·분리/병합·시각 ±0.1초. **‘발화 삭제’** 는 그 구간의 영상·음성을 비파괴로 잘라내며 되돌릴 수 있습니다(글자 수정과 별개).
5. 미리보기에서 영상·제목·자막·로고 상자를 끌어 이동/크기 조정(가운데 자동 정렬, 방향키 1px·Shift 10px). 오른쪽 **스타일·템플릿** 탭에서 숫자로 미세 조정, 범위(클립 전체/현재 문장) 선택, 템플릿 저장·적용.
6. **구간·속도** 탭: 구간 변경, 배속(0.5~2.5), 무음 찾기(제안 → 선택해 적용), 삭제 구간(EDL) 목록.
7. **MP4 내보내기**(1080×1920) 또는 **확정 미리보기**(540×960 실제 렌더) · 여러 클립 **일괄 MP4 + ZIP**. 진행률은 FFmpeg가 보고한 실제 값입니다.

키보드: `Space` 재생/정지 · `Ctrl+S` 저장 · `Ctrl+Z`/`Ctrl+Shift+Z` 실행 취소/다시 실행 · `Alt+↑/↓` 이전/다음 문장.

## 4. 입력·출력 위치

| 구분 | 위치(기본, `.env`의 `JSS_DATA_DIR`로 변경) |
|---|---|
| 업로드한 원본 사본(수정 금지) | `data/sources/` |
| 전사용 오디오·자막 이미지·썸네일·프록시 캐시 | `data/cache/` |
| 렌더링 임시 파일(검사 통과 전) | `data/tmp/` |
| **완성 MP4·SRT·ZIP** | `data/outputs/<프로젝트ID>/` (파일명 `프로젝트_순번_클립제목.mp4`) |
| 프로젝트 DB(SQLite) | `data/studio.sqlite3` |

파일명은 Windows 금지문자(`<>:"/\|?*`)·예약어·길이·중복을 자동 처리합니다. 다시 렌더링해도 이전 성공본을 지우지 않습니다(`_2`, `_3` …).

## 5. API 키·모델·비용

| 기능 | 처리 위치 | 비용 | 필요한 것 |
|---|---|---|---|
| 영상 검사·렌더링·무음 감지·프록시 | 로컬 FFmpeg | 외부 요금 없음(PC 자원·시간 사용) | FFmpeg |
| 자동 전사(한국어) | 로컬 faster-whisper | 외부 요금 없음 | 첫 실행 시 Hugging Face에서 모델 다운로드(인터넷) 또는 `JSS_WHISPER_MODEL`에 로컬 모델 폴더 |
| AI 구간 추천 | Anthropic Claude API | **사용량 과금** | `.env`의 `ANTHROPIC_API_KEY`, 모델 `JSS_ANTHROPIC_MODEL`(기본 `claude-opus-5-5`) |

- AI 추천은 실행 전에 **전송 데이터(전사문 텍스트만, 영상·음성은 보내지 않음)·입력 토큰 수·예상 요금**을 보여주고 확인을 받습니다. 단가(`JSS_PRICE_*`)를 넣지 않으면 ‘비용 미확인’으로 표시합니다.
- 같은 전사본·모델·설정의 추천 결과는 재사용합니다. 자막 색·템플릿만 바꾸면 다시 분석하지 않습니다. 전사본을 고치거나 설정을 바꾸면 새로 분석합니다.
- 키는 서버 쪽 `.env`에만 있고 브라우저로 전송되지 않으며 로그·오류 메시지에서 가려집니다.

## 6. 오류 확인

오른쪽 위 **작업** 버튼 → 작업별 상태(대기/실행 중/성공/실패/취소됨/중단됨), 단계, 경과 시간, 오류 코드·한국어 안내, 로그, 취소·재시도.
대표 오류: FFmpeg 없음 · 손상/가짜 영상 · 디스크 부족 · 전사 모델 없음 · API 키 오류 · 사용 한도 초과 · 네트워크 단절 · 시간 초과.

## 7. 테스트

```bash
pip install -r requirements-dev.txt
python -m pytest tests -q                       # 실제 FFmpeg 렌더링·동기화 측정 포함(약 2분)
python run.py --no-browser &                    # 브라우저 검수용 서버
python tests/ui_e2e.py http://127.0.0.1:8765 <영상.mp4> <자막.srt> docs/evidence/ui
python tests/ui_preview_match.py http://127.0.0.1:8765 <영상.mp4> <자막.srt> docs/evidence/a09
python tools/make_samples.py                    # samples/ 다시 생성
```

## 8. 업데이트

새 코드를 받은 뒤 `설치.cmd`를 다시 실행하면 패키지가 갱신됩니다. 데이터베이스는 시작할 때 자동으로 마이그레이션됩니다(현재 스키마 v2). 업데이트 전 `data/` 폴더를 백업해 두면 안전합니다.
